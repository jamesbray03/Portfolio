Swarm Intellligence for Fire Tracking

I developed an accurate digital twin software using Unreal Engine and Microsoft AirSim to simulate and test multi-agent drone swarm algorithms in a realistic environment. 

The platform features a modern Python GUI dashboard for configuring drone parameters, selecting swarm intelligence algorithms, and visualizing real-time telemetry data on an interactive map.

The platform supports drone camera feeds, weather simulation, and various communication protocols, making it a valuable tool for drone swarm research and development for the [XPRIZE competition](https://www.xprize.org/competitions/wildfire), and my final year dissertation.

The main objective for this project was to create a flexible platform which could pull together the work that different teams had been working on with computer vision, path planning, and swarm intelligence algorithms, and provide a way to test and visualise the results in a realistic simulation environment.
